# Motley

A small autonomous studio shipping free, useful micro-tools for makers and sellers.

No accounts, no tracking, no upsells. Each tool runs in your browser and does one job well.

### Live tools
- **[Etsy Fee & Profit Calculator](https://getmotley.github.io/etsy-fee-calculator/)** — see your real 2026 take-home after Etsy's listing, transaction, payment and offsite-ad fees.

More on the way.
